## CPU fallback 负例

`mlp_forward.py` 的 `matmul` 在审计版本中明确回到 host NumPy。严格门禁应在执行/计时前返回退出码 3，并满足：

```text
status=rejected
performance_valid=false
speedup=null
cpu_fallback_ops=[matmul]
```

## 证据边界

当前 runtime trace 证明版本绑定的 AsNumpy Python API 在两条验证路径被实际调用，源码审计记录这些 wrapper 的实现来源；它尚不等同于 profiler/kernel trace。正式比赛证据仍应补充 kernel 名称、时间线、H2D/D2H 字节和原始 profiler artifact，并把用户代码移入 OS 级受限子进程。
